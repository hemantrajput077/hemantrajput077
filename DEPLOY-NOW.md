## 🔧 Troubleshooting

### "Repository already exists"
**Solution:** Delete existing repo or use different name

### "Permission denied" when pushing
**Solution:** 
- Use GitHub Desktop app, OR
- Generate Personal Access Token at: https://github.com/settings/tokens
- Use token as password when prompted

### Snake animation not showing
**Solution:**
- Wait 1-2 minutes after workflow completes
- Hard refresh page: `Ctrl + Shift + R`
- Verify workflow completed successfully in Actions tab

### Stats not loading
**Solution:**
- Wait 2-3 minutes for services to initialize
- Hard refresh: `Ctrl + Shift + R`
- Check Vercel services status (external dependencies)
