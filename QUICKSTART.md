## 🚀 3-Step Deployment

### Step 1: Create Repository (1 minute)

1. **Go to:** https://github.com/new

2. **Fill in:**
   - Repository name: `hemant-rajput04` ⚠️ Must be EXACT
   - Description: `My GitHub Profile`
   - Visibility: ✅ **Public** (REQUIRED)
   - ❌ DO NOT check "Initialize with README"

3. **Click:** "Create repository"

---

### Step 2: Upload Files (2 minutes)

**Open Git Bash / Terminal** and run:

```bash
# Navigate to folder
cd C:/allaboutpython/TalkTribe/github-profile

# Initialize git
git init

# Add all files
git add .

# Commit
git commit -m "Add premium GitHub profile"

# Connect to GitHub
git remote add origin https://github.com/hemant-rajput04/hemant-rajput04.git

# Push to GitHub
git branch -M main
git push -u origin main
```

**Enter your GitHub credentials when prompted.**

---

### Step 3: Enable & Run Workflow (2 minutes)

#### 3A. Enable Permissions

1. **Go to:** https://github.com/hemant-rajput04/hemant-rajput04/settings/actions

2. **Scroll to:** "Workflow permissions"

3. **Select:**
   - ✅ Read and write permissions
   - ✅ Allow GitHub Actions to create and approve pull requests

4. **Click:** Save

#### 3B. Run Snake Animation

1. **Go to:** https://github.com/hemant-rajput04/hemant-rajput04/actions

2. **Click:** "Generate Snake Animation" (left sidebar)

3. **Click:** "Run workflow" button (right side)

4. **Select:** Branch: `main`

5. **Click:** "Run workflow" (green button)

6. **Wait:** ~30 seconds for ✅ green checkmark

## 🔧 Quick Fixes

### "Repository already exists"
**Solution:** Choose a different name or delete existing repo first.

### "Permission denied"
**Solution:** 
- Check GitHub credentials
- Generate Personal Access Token at: https://github.com/settings/tokens
- Use token as password

### "Stats not loading"
**Solution:** 
- Wait 2-3 minutes
- Hard refresh page
- Verify username is `hemant-rajput04` (no typos)

### "Workflow failed"
**Solution:** 
- Check Step 3A completed correctly
- Re-run workflow
- Check Actions tab for error details
